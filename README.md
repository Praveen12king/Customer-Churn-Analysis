# Customer Churn Analysis Dashboard

## Project Overview
This Power BI dashboard analyzes customer churn behavior using customer demographics, contract types, payment methods, monthly charges, and tenure data.

The dashboard helps identify:
- Customers likely to churn
- Revenue impact of churn
- Contract-based churn patterns
- Service usage trends

---

## Tools & Technologies Used
- Power BI
- DAX
- Excel / CSV Dataset
- Data Visualization
- Business Intelligence Techniques

---

## Key Insights
- Customers with month-to-month contracts show higher churn rates.
- Higher monthly charges are associated with increased churn.
- Fiber optic internet users have higher churn compared to DSL users.
- Long-term customers are less likely to churn.
